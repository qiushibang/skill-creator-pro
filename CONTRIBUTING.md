# Contributing

Thanks for your interest in improving `skill-creator-pro`.

## Scope

This repository is maintained as a **skill-only public repository**. Contributions should focus on improving the skill itself, including:

- `SKILL.md`
- `scripts/`
- `assets/`
- `references/`
- `agents/`
- `README.md`

Please avoid adding local development noise or generated artifacts such as:

- `dist/`
- `reports/`
- `.pytest_cache/`
- temporary export files
- system files such as `.DS_Store`

## Recommended workflow

1. Create a branch for your change
2. Keep edits focused and minimal
3. Update documentation when behavior or usage changes
4. Run local validation before submitting a PR when relevant

## Pull request guidance

A good PR should explain:

- what changed
- why it changed
- whether the change affects packaging, documentation, or usage
- whether any follow-up cleanup is needed
