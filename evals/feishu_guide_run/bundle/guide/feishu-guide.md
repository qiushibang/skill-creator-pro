## 技能简介

这是一个适配多 Agent 的单包 Skill 自动开发器。它把需求澄清、计划、开发、测试、评审、飞书图文指南和 Agent 安装包打包整合进一个技能目录里，目标是让用户只安装这一个技能就能完成从需求描述到 skill 交付的闭环。

## 适用场景

- 把重复工作沉淀成可复用 skill
- 希望自动完成需求澄清、计划、开发、测试、评审与打包
- 希望最终自动产出飞书使用指南和介绍画板
- 不想额外安装 brainstorming、superpowers、lark-doc、design-lark-chart 等多个技能

## 触发方式

- 帮我做一个 skill
- 把这个流程沉淀成技能
- 帮我自动生成 Agent 可安装 skill
- 帮我给 skill 生成飞书指南和画板

## 输入 / 输出

### 输入
- 自然语言需求描述
- 可选的已有 skill/脚本/参考资料
- 可选的飞书文档目标位置

### 输出
- 可安装的 skill 目录
- Agent 兼容安装包
- 测试/评审/安全摘要
- 飞书使用指南
- 默认介绍画板与文档插入计划

## 使用步骤

1. 生成显式需求澄清摘要，确认目标/输入/输出/约束/验收标准
2. 检索可复用 skill 与参考资料，判断 simple / complex
3. 创建 task_plan / findings / progress，并停在 Gate 1 等待确认
4. 用户确认后进入开发与验证，持续更新执行状态与证据
5. 汇总测试、评审、安全摘要，并停在 Gate 2 等待验收
6. 用户验收通过后，生成飞书使用指南、画板与命令计划
7. 完成 Agent 安装包打包，输出 zip 与安装清单

## 限制与注意事项

- 正式开发前必须经过 Gate 1 确认
- 最终交付前必须经过 Gate 2 验收
- 没有验证证据不能宣称完成
- 如果外部飞书权限或画板写入受限，会降级为本地交付包

## 常见问题

- **为什么这个 skill 要集成多个能力？**
  - 因为原始能力通常分散在 brainstorming、superpowers、skill-creator、lark-doc、design-lark-chart 等多个 skill 中，真实使用时需要频繁切换，体验割裂。
- **它会自动生成飞书画板吗？**
  - 会。默认会生成介绍当前 skill 的画板，并给出插入文档的 action plan；若外部环境受限，则先输出本地 board spec 与命令计划。
- **是否还需要单独安装 design-lark-chart？**
  - 不需要。当前 skill 已经内置了轻量图表流水线和默认介绍板生成能力。
