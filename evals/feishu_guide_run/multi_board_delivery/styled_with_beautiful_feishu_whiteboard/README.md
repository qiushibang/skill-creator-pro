# beautiful-feishu-whiteboard 接入说明

## 已选风格
- 画板 1：Riso Brut（备选：Neo-Grid Bold）
- 画板 2：Raw Grid（备选：Cobalt Glaze）

## 推荐插入位置
- 画板 1：插入到“技能简介”后
- 画板 2：插入到“使用步骤”后

## 使用方式
把对应 prompt 直接交给已安装的 beautiful-feishu-whiteboard skill。
如果当前环境已完成 lark-cli auth login，则可继续把生成的画板写入目标飞书文档。
如果尚未完成认证，则先生成风格化白板方案，待认证后再执行写入。
